# Maktaba Portable — تطبيق سطح مكتب (Windows)

برنامج إدارة المكتبة والخدمات كـ **نافذة ويندوز** (Electron + SQLite).  
البيانات على **هذا الجهاز فقط**.

> السيرفر الشبكي: `ahosam3030/Maktaba` — منفصل.

## أول تشغيل
1. ثبّت [Node.js 20+](https://nodejs.org)
2. دبل كليك **`اول-تشغيل.bat`**

أو: `build-desktop.bat` → `seed.bat` → `تشغيل التطبيق.vbs`

## مثبّت
`تثبيت البرنامج.bat` → `release\Maktaba-Setup-*.exe`
