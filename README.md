# Maktaba Portable v1.3.2 — منتج سطح مكتب

تطبيق Windows (Electron + SQLite) لمراكز الخدمات والمكتبات.

## للمستخدم النهائي

1. ثبّت البرنامج من `Maktaba-Setup-*.exe` (بعد بنائه بـ `تثبيت البرنامج.bat`)
2. افتح **Maktaba** من سطح المكتب
3. أول مرة: املأ شاشة **إعداد البرنامج لأول مرة**
4. اعمل يوميًا من نفس الاختصار

**لا تستخدم seed.bat عند العميل** — يُستخدم للتطوير فقط ويمسح البيانات.

### أين البيانات؟
خارج مجلد التثبيت:
`%APPDATA%\\Maktaba\\maktaba-data\\`  
(قاعدة `maktaba.db` + نسخ احتياطي + صور)

### نسخ احتياطي
- تلقائي يوميًا في `maktaba-data/backups`
- يدوي: قائمة **ملف → نسخة احتياطية**

## إصلاحات v1.3 (جاهزية البيع)
- بيانات العميل في AppData (لا تُمسح مع إلغاء التثبيت)
- إنشاء جداول SQLite تلقائيًا عند التشغيل
- تشغيل الـ API عبر Electron (بدون تثبيت Node عند العميل)
- JWT_SECRET و LICENSE_SECRET ثابتان في config.json
- استعادة قاعدة بعد إيقاف الـ API
- بورت احتياطي إن كان 3000 مشغولًا
- إصدار مفاتيح الترخيص معطّل في نسخة العميل

## حدود
جهاز واحد — لا مزامنة شبكية. للشبكة: ريبو `Maktaba`.
