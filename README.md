# Maktaba Portable — تطبيق سطح مكتب (Windows)

نظام إدارة المكتبة والخدمات كـ **برنامج ويندوز** (Electron) — **لا يفتح المتصفح**.

- قاعدة **SQLite** محلية: `data/maktaba.db`
- ريبو **Maktaba** (PostgreSQL / الشبكة) منفصل ولم يُعدَّل

---
## لماذا كانت تظهر نافذة CMD؟

التشغيل القديم عبر `.bat` يبقي الطرفية مفتوحة طالما البرنامج يعمل.

**الآن:**
- **`تشغيل التطبيق.vbs`** أو **`تشغيل التطبيق.bat`** → تفتح نافذة البرنامج فقط (بدون CMD ظاهرة)
- **`إنشاء اختصار سطح المكتب.bat`** → اختصار مثل أي برنامج عادي
- للتجربة النهائية كتطبيق مستقل: **`build-release.bat`** → ملف `.exe` في مجلد `release\`



## التشغيل (نافذة برنامج)

| الخطوة | الملف |
|--------|--------|
| 1. ثبّت | [Node.js 20+](https://nodejs.org) |
| 2. أول مرة | دبل كليك **`build-desktop.bat`** (بناء مرة واحدة) |
| 3. التشغيل دائمًا | دبل كليك **`تشغيل التطبيق.bat`** أو **`start-desktop.bat`** |
| 4. أول حساب | **`seed.bat`** → YES → بريدك + كلمة مرور قوية |

بعد الخطوة 3 تفتح **نافذة Maktaba** مباشرة (مش Chrome/Edge).

### بناء ملف .exe للتوزيع
```bat
build-desktop.bat
build-release.bat
```
المخرجات في `release/` :
- `Maktaba-Portable-*.exe` — تشغيل بدون تثبيت (portable)
- مثبّت NSIS مع اختصار سطح المكتب

## الملفات المهمة

| الملف | الوظيفة |
|--------|---------|
| `تشغيل التطبيق.bat` | فتح نافذة البرنامج |
| `start-desktop.bat` | نفس التشغيل |
| `build-desktop.bat` | بناء API + الواجهة + Electron |
| `build-release.bat` | حزم .exe للتوزيع |
| `seed.bat` | إنشاء المالك |
| `backup.bat` / `restore-backup.bat` | نسخ احتياطي |
| `start.bat` | يوجّه لتشغيل سطح المكتب |
