# Maktaba Portable **v1.5.0**

تطبيق Windows (Electron + SQLite) لإدارة مراكز الخدمات والمكتبات ومكاتب الطباعة.

> **البناء:** [RELEASE.md](RELEASE.md) · **الاختبار:** [TEST-CHECKLIST.md](TEST-CHECKLIST.md) · **الجاهزية:** [READY.md](READY.md)

---

## للمستخدم النهائي

1. ثبّت من **`Maktaba-Setup-1.5.0.exe`** (من مجلد `release\` بعد البناء، أو من [GitHub Releases](https://github.com/ahosam3030/Maktaba-Portable/releases))
2. افتح **Maktaba** من سطح المكتب
3. أول مرة: أكمل شاشة **إعداد البرنامج لأول مرة**
4. اعمل يوميًا من نفس الاختصار

**لا تستخدم `seed.bat` عند العميل** — للتطوير فقط ويمسح البيانات.

### أين البيانات؟

```text
%APPDATA%\Maktaba\maktaba-data\
```

(قاعدة `maktaba.db` + نسخ احتياطي + صور) — **لا تُمسح** مع إلغاء التثبيت.

### نسخ احتياطي

- تلقائي يوميًا في `maktaba-data/backups`
- يدوي: من داخل البرنامج أو `backup.bat`

```text
preflight-check.bat
build-release.bat
→ release\Maktaba-Setup-1.5.0.exe
```

يتطلب Node.js 20+ على **جهاز البناء فقط**. العميل لا يحتاج Node بعد التثبيت.

## ما في هذا الإصدار

- Electron + SQLite محلي (جهاز واحد)
- Migration آمنة + bootstrap بدون مسح بيانات قائمة
- ترخيص Ed25519 (MAK2) — الإصدار من نسخة العميل معطّل
- بيانات العميل في AppData
- نسخ احتياطي + فحص سلامة
- تحديث تلقائي عبر GitHub Releases (بعد نشر الـ Release)
- مبيعات آجل مع حسابات عملاء
