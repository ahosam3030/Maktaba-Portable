# Maktaba Portable v1.2 — منتج سطح مكتب

تطبيق Windows لإدارة مركز الخدمات والمكتبة (Electron + SQLite).  
**جهاز واحد · بيانات محلية · بدون متصفح ظاهر.**

## للمستخدم النهائي

| الخطوة | الإجراء |
|--------|---------|
| 1 | ثبّت [Node.js 20+](https://nodejs.org) على جهاز البناء |
| 2 | **`اول-تشغيل.bat`** أو ابنِ مثبّتًا عبر **`تثبيت البرنامج.bat`** |
| 3 | عند أول فتح: املأ **إعداد البرنامج لأول مرة** |
| 4 | الاستخدام اليومي من اختصار **Maktaba** |

### النسخ الاحتياطي
- تلقائي يومي في مجلد `backups/`
- يدوي: قائمة البرنامج ← ملف ← نسخة احتياطية

### التقارير
من شاشة التقارير: تصدير Excel (CSV) أو طباعة/PDF
